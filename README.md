# Inventory-Management-System

## Overview

The Inventory Management System is a retail store management application developed in C. The system provides inventory control, employee management, customer billing, and role-based authentication for managers and sales personnel.

The project simulates real-world retail operations and demonstrates the implementation of data structures, file handling, and business logic automation.

---

## Features

### Authentication System

* Manager Login
* Salesman Login
* Password Management
* Role-Based Access Control

### Inventory Management

* Create Product Inventory
* Add New Products
* Remove Products
* Update Product Quantities
* Sort Products Alphabetically
* View Available Inventory

### Sales Operations

* Product Purchase Processing
* Automatic Stock Updates
* Customer Billing System
* Receipt Generation
* Transaction Recording

### Employee Management

* Add Employees
* Remove Employees
* Employee Information Storage
* Employee List Management

### File Management

* Persistent Data Storage
* Inventory Records
* Sales Records
* Employee Records
* Billing Records
